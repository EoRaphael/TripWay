# ✈️ TripWay

Bem-vindo ao **TripWay**, o seu portal para descobrir e planejar viagens para destinos inesquecíveis! 

## Sobre o Projeto
O TripWay é um site interativo focado em turismo e exploração de viagens. Através da nossa plataforma, os usuários podem descobrir pacotes para destinos incríveis como Fortaleza, Lisboa e Liverpool, conhecer nossos serviços especializados e entrar em contato facilmente com a nossa equipe.

## Tecnologias Utilizadas
* **HTML5:** Estruturação semântica das páginas.
* **Multimídia:** Imagens de alta qualidade em JPG e PNG para destacar os destinos.

## Estrutura do Projeto

A organização de pastas do projeto foi pensada para manter a clareza e facilitar a manutenção:

```text
TripWay/
├── index.html              # Página inicial (Home) destacando as melhores viagens
├── pages/                  # Páginas secundárias do site
│   ├── destination.html    # Catálogo e detalhes dos destinos (Lisboa, Liverpool, etc.)
│   ├── services.html       # Descrição dos pacotes e serviços oferecidos
│   └── contact.html        # Página com formulário de contato
└── images/                 # Diretório de assets gráficos
    ├── banner.jpg
    ├── Services-Banner.png
    └── ... (fotos dos destinos)
```

## Como Executar o Projeto

Como é um projeto puramente voltado para o Front-end (HTML/CSS), não é necessária a instalação de dependências complexas.

1. Faça o clone deste repositório em sua máquina local:
   `git clone <url-do-seu-repositorio>`
2. Navegue até a pasta do projeto:
   `cd TripWay`
3. Dê um duplo clique no arquivo `index.html` para abri-lo em seu navegador padrão.
